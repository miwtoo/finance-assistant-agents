# Issue Tracker

**Repo:** `git@github.com:miwtoo/finance-assistant-agents.git`

## Principles

- GitHub Issues is the project's single source of truth for planned work.
- Issues are agent-ready: each contains acceptance criteria, blocking edges, and a short implementation sketch where applicable.
- Labels drive triage — see [triage-labels.md](triage-labels.md).

## External PRs

External PRs (from forks or contributors outside the core team) are **not** a request surface for this project. They are not triaged, reviewed, or merged unless explicitly planned in an issue. Do not treat external PR activity as signals for prioritisation.
